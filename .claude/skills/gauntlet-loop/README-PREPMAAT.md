# Gauntlet Loop in PrepMaat

Gekopieerd uit https://github.com/duolahypercho/gauntlet-loop (MIT-licentie, zie LICENSE).
Doordat deze skill in `.claude/skills/` van de repository staat, werkt hij in elke
Claude Code-sessie op deze repository, ook in de cloud. Je hoeft niets te installeren.

Gebruik (in Claude Code):

    /gauntlet-loop verbeter de Boodschappen-tab van PrepMaat. Stop na maximaal 3 rondes en vraag mij om akkoord.

Let op: de skill is gemaakt voor games en stopt niet vanzelf. Geef daarom altijd een
maximum mee (aantal rondes), anders draait hij door tot je Claude-limiet op is.
